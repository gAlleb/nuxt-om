## Что это

Фронтенд интернет-радио на несколько станций, собранный на Nuxt 4. Семь станций, два
независимых источника now-playing, воспроизведение через HLS и Icecast, спектроанализатор
в реальном времени, десятиполосный эквалайзер, поиск обложек — и интерфейс, который
перекрашивается под обложку играющего трека.

Интересное здесь не список возможностей, а то, что **добавление станции — это один объект
в одном файле**. Никаких новых страниц, компонентов и проводки по коду. Дописал в реестр —
и у сайта появились страница, карточка, пункты меню, кружок в плеере, подписка на SSE
и собственные SEO-метатеги.

## Как добавить станцию

Всё лежит в [`app/config/stations.ts`](./app/config/stations.ts). Дописываете один объект:

```ts
{
  id: 'jazz',                 // mount плеера и ключ во всех сторах
  slug: 'jazz',               // /streams/jazz
  provider: 'azuracast',      // откуда приходит now-playing
  channel: 'station:jazz',    // имя канала у этого провайдера

  hls: 'https://radio.example.com/hls/jazz/live.m3u8',
  icecast: 'https://stream.example.com:8443/jazz',

  text: {
    menu: 'Jazz @ omFM',      // меню выбора стрима и кнопка на карточке
    card: 'Jazz',             // подпись под карточкой
    hero: 'JazzFM',           // заголовок страницы станции
    tagline: 'дымные залы и щётки по малому',
    logo: 'Jazz',             // <sup> рядом с логотипом в шапке
    panel: 'JazzFM',          // заголовок выезжающей панели плеера
    thumb: 'Jazz',            // кружок в свипере плеера
    tab: 'Jazz',              // таб на /streams
  },

  look: {
    font: "'Tenor Sans', sans-serif",           // любой CSS font-family
    radial: 'radial-gradient(#0056fb29, #ff00fb26)',   // подсветка интерфейса
    accent: 'border border-amber-500/50',       // рамка активной карточки
  },

  images: {
    heroLight: '/jazz.jpg',
    heroDark: '/jazz.jpg',
    card: '/jazz.jpg',
    thumb: 'rock-00-thumb.jpg',                 // из app/assets/img/
  },

  visualizer: {},               // пусто — возьмутся встроенные цвета
  showNext: true,
  artSource: 'station',         // 'itunes' — искать обложки в iTunes
  historyCount: 5,
}
```

Дальше `npm run generate`. Это вся процедура.

Свой шрифт? Объявите его через `@font-face` и укажите семейство в `look.font` —
правок в CSS не нужно, переменные оформления генерируются из реестра.

### Если станция на AzuraCast — совсем просто

AzuraCast уже отдаёт now-playing по SSE ровно в том виде, который проект и ожидает, поэтому
**заполняете только данные самой станции** — остальное берёт на себя провайдер:

```ts
provider: 'azuracast',
channel: 'station:<shortcode>',    // shortcode станции в AzuraCast
```

Свой сервер AzuraCast прописывается один раз, в этом же файле:

```ts
export const providers = {
  azuracast: {
    sseUrl: 'https://ваш-azuracast.example.com/api/live/nowplaying/sse',
    dedupeBy: 'sh_id',
    historyOffset: 0,
    coverFallback: 'stationArt',
  },
}
```

После этого все станции с этого сервера делят одно SSE-соединение. Десять станций — один сокет.

### Другой бэкенд?

Добавьте провайдера рядом с `azuracast`. В проекте их два: AzuraCast и обычный мост через
[Centrifugo](https://centrifugo.dev/). Провайдер описывает ровно те четыре вещи, которыми
бэкенды реально отличаются:

| поле | на какой вопрос отвечает |
|---|---|
| `sseUrl` | куда подписываться |
| `dedupeBy` | как понять, что трек сменился (`sh_id` или текст трека) |
| `historyOffset` | история начинается с текущего трека или с предыдущего |
| `coverFallback` | если обложка не нашлась — подставить арт станции или заглушку |

Станция просто указывает, к какому провайдеру относится. Смешанные конфигурации работают:
сейчас пять станций приходят с AzuraCast и две с Centrifugo, у каждого свои особенности —
и ни один компонент об этом не знает.

## Что станция получает сама собой

- **Свою страницу** `/streams/<slug>` — герой, кнопка play, спектроанализатор, now playing,
  следующий трек, история, — плюс преднарисованные SEO-заголовок и описание, во всех трёх локалях.
- **Карточку** на главной и слайд в карусели «Top stations».
- **Пункты** в меню шапки, в мобильном меню, в выборе стрима и в табах `/streams`.
- **Кружок** в свипере плеера и в мобильном выпадающем списке.
- **Подписку на SSE**, сгруппированную с остальными станциями того же провайдера.
- **Оформление под себя**: шрифт интерфейса, радиальная подсветка и акцентный цвет следуют
  за выбранной станцией.

## Возможности

**Воспроизведение** — HLS через hls.js с запасным Icecast, переключается на лету. Громкость,
mute и десятиполосный эквалайзер работают через граф Web Audio и переживают перезагрузку.
Медиаклавиши и системный виджет «сейчас играет» подключены через Media Session API.

**Живые данные** — по одному SSE-соединению на бэкенд, автоматическое переподключение,
прогресс трека, который продолжает идти между обновлениями.

**Обложки** — ищутся в iTunes с кэшем и аккуратным откатом на арт самой станции. Из текущей
обложки извлекается доминирующий цвет и подкрашивает плеер и карточки, а цвет текста
подбирается по контрасту.

**Визуализация** — спектр на canvas и трёхполосная волна, плюс плёночные эффекты (радиальная
подсветка, зерно, строки развёртки, мерцание) — каждый включается отдельно и запоминается.

**Тема** — тёмная и светлая, переключается кругом, расходящимся из точки клика через View
Transitions, и уважает `prefers-reduced-motion`.

**Контент** — блог и статические страницы на Nuxt Content v3, на английском, русском и испанском.

Настройки применяются атрибутами на `<html>` до гидратации, поэтому статическая сборка и
серверная ведут себя одинаково — без мигания состоянием по умолчанию.

## Установка

```bash
npm install
```

Сервер разработки на `http://localhost:3000`:

```bash
npm run dev
```

> Нужен Node 22.19+ (требование Nuxt 4). Nuxt Content v3 использует `better-sqlite3` — это
> нативный модуль, и на slim-образе Linux для его сборки понадобятся `python3`, `make` и `g++`.

## Развёртывание

**Обычный хостинг** (Plesk, cPanel, любой веб-сервер):

```bash
npm run generate
```

Содержимое `.output/public` кладётся в корень сайта.

**Node-сервер:**

```bash
npm run build
node .output/server/index.mjs
```

**Docker:**

```bash
docker compose up -d
```
